# Curriculum

Part of [HTML Practice](../README.md). This folder is the source of truth for what the course teaches. Graded pages stay in [practices/README.md](../practices/README.md). Notebooks stay in [labs/README.md](../labs/README.md).

Each module folder can be read on its own. A presentation tool or a notebook source needs that folder, not the test runner and not an answer branch.

## Files in a module

| File | What it is for |
| --- | --- |
| [specification.md](modules/html.text/specification.md) | Objectives, prerequisites, and the exercises that belong to the module |
| [study-guide.md](modules/html.text/study-guide.md) | The explanation a student or a teacher reads before the exercises |
| [presentation-outline.md](modules/html.text/presentation-outline.md) | Slide-by-slide classroom outline |
| [podcast-brief.md](modules/html.text/podcast-brief.md) | Discussion brief for an audio lesson |
| [assessment.md](modules/html.text/assessment.md) | How understanding is checked, and which objective each check belongs to |

The text links above are the pattern. Every existing module uses the same five files.
