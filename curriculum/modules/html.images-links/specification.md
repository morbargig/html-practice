## Prerequisites

[html.text](../html.text/specification.md). The student can add one element in `body` and can match a string exactly.

## Learning objectives

1. Add one `img` with `src="images/photo.jpg"` and `alt="My Photo"`.
2. Add one absolute link to `https://example.com` with visible text `Visit Site` and `target="_blank"`.
3. Add one relative link to `contact.html` with visible text `Contact`.
4. Put the image and the external link on one page.
5. Explain why a missing `alt`, a wrong `href`, or the words outside the `a` fail, and why `contact.html` does not need to exist for the markup test.

## Outcomes

A student can point an image at a file, describe it, distinguish an absolute URL from a relative one, and repair a link whose text or `href` does not match.
