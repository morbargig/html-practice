# Podcast brief: lists

## Questions

- What did the profile list already prove?
- Why must the steps stay in order?
- Who draws the numbers?

## Explanations

`ul` is the set of topics. `ol` is the sequence of steps. The browser paints bullets or numbers from the tag. Typed numbers become part of the text the test compares. The items are not the profile items.

## Example

Ingredients in a `ul`, and "heat, add, serve" in an `ol`. Ask what breaks if those tags swap. Do not use the graded topic names as the example's items.

## Misconceptions

- This chapter is a repeat, so the profile list should be pasted in.
- The brief's `1. 2. 3.` means the HTML should contain those digits.
- One list of six `li` elements satisfies both checks.

## Debugging scene

The found unordered items are Headings, Links, Images. That is the profile page. This page wants Paragraphs in the middle.

## Prompts

- When is a definition list a better fit, and why is it not graded here?
- Can an ordered list restart at 1 for a second procedure? Yes. This page has one procedure.
- How will the About Me interests list choose between `ul` and `ol`? Interests are a set.
