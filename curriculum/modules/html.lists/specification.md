## What is new

The profile chapter already graded one `ul` with the items `Headings`, `Links`, and `Images`. This exercise uses different bullets, `Headings`, `Paragraphs`, and `Links`, and adds an `ol` whose steps are `Create the file`, `Add a heading`, and `Save the page`.

## Objectives

1. Write one `ul` with those three topics in that order.
2. Write one `ol` with those three steps in that order.
3. Explain why the step numbers come from `ol`, not from typing `1.` into the text.

## Contract

One `ul` and one `ol`. Item text and order are exact. The test reads `li` children of each list.

## Outcomes

A student can choose `ul` for a set and `ol` for a sequence, and can see that the profile list was a different set.
