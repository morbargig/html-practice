## Objectives

1. Add one `ul` whose items are exactly `Headings`, `Links`, and `Images`, in that order.
2. Build Alex Rivera's skeleton: `header` with `h1` `Alex Rivera`, `nav` links `About` to `#about` and `Contact` to `#contact`, `main id="about"` with `I am learning HTML.`, `section id="contact"` with `h2` `Contact`, and a footer `© 2026 Alex Rivera`.
3. Build the full profile: bio `I am learning to build web pages with HTML.`, image `images/photo.jpg` with alt `Alex Rivera`, skills `HTML`, `Accessibility`, `Tables`, a contact form with connected required name, email, and message textarea, button `Send`, and a GitHub link to `https://github.com/alexrivera`.
4. Explain why `#about` does nothing until some element has `id="about"`.

## What is new

The list is the first graded `ul`. The regions are the first graded landmarks. The full page combines them. Lesson 02 repeats lists and landmarks with different text and extra elements. It is not a replacement for this chapter.

## Outcomes

A student can group three items, point navigation at ids, and assemble one profile without dropping the label connections from the form chapter.
