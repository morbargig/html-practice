# html.semantics — Article, aside, and a landmark page

The profile chapter graded `header`, `nav`, `main`, `section`, and `footer`. This module adds `article` and `aside`, then a page that uses both with a heading outline.

## Objectives

1. Write an `article` titled `First Post` with `This note stands on its own.`, and an `aside` titled `Note` with `Asides are related, not the main story.` Use `h2` for both titles.
2. Build the Campus News page: `lang="en"`, title `Campus News`, header `h1`, nav `Story` to `#story` and `Notes` to `#notes`, `article id="story"` and `section id="notes"` inside `main`, an aside `Related` / `Bring a notebook.`, and footer `© 2026 Campus News`.
3. Explain why an aside is related content, not a second article, and why the story's `h2` must not skip past the page `h1`.

## Outcomes

A student can choose `article` for a piece that stands alone and `aside` for a note beside it, then place both in a page that still has one outline.
