# html.text-meaning — Emphasis and heading order

| | |
| --- | --- |
| Status | Existing |

Lesson 01 already graded one `h1`. This module adds emphasis inside a sentence, and a heading outline that does not skip a level.

## Objectives

1. Write one paragraph, `HTML gives content meaning and importance.`, with `meaning` in `em` and `importance` in `strong`.
2. Write the outline `h1` Recipes, `h2` Breakfast, `h3` Oatmeal, `h2` Dinner, with no skipped levels and no extra heading.
3. Explain why `h1` then `h3` fails even when the words are right, and why `em` is not the same instruction as `strong`.

## Exercises

| Exercise | Contract |
| --- | --- |
| [Emphasis](../../../practices/lesson-02/01-text/01-emphasis/README.md) | One `p` with that full sentence. One `em` whose text is `meaning`. One `strong` whose text is `importance` |
| [Heading Hierarchy](../../../practices/lesson-02/01-text/02-heading-hierarchy/README.md) | That sequence. The first heading must be `h1`. A level may rise by at most one |

## Outcomes

A student can mark a word inside a sentence and can build an outline that steps down and back up without jumping.
