# Assessment: headings and paragraphs

Three exercises, each with its own `test.js`. An untouched starter fails. That failure is the unfinished page. Do not change the expected strings so a partial page passes.

Lab 01 Exercise 1 overlaps this module and accepts any non-empty `h1` and `p`. Passing the lab does not pass these three exercises.

## Traceability

| Objective | Study section | Exercise | Check | Slide | Podcast prompt |
| --- | --- | --- | --- | --- | --- |
| 1. One `h1`, text `Hello World` | What these elements are | [01-hello-heading](../../../practices/lesson-01/01-text/01-hello-heading/README.md) | Exactly one `h1`. Text equals `Hello World` | 2 | Why the tab title is not the heading |
| 2. One `p`, text with the exclamation mark | How the test reads the page | [02-paragraph](../../../practices/lesson-01/01-text/02-paragraph/README.md) | Exactly one `p`. Text equals `Welcome to HTML in VS Code!` | 3 | Enter versus a paragraph |

| 4. Explain a duplicate or a typo | How to debug | All three | The message names the found text or the found count | 4 | The missing exclamation mark |
| 5. A different sentence, same tags | The harbor example | Ungraded scratch page | No automated check | 5 | Harbor notes |

## Criteria

- Each exercise passes on its own folder. Copying the heading file over the combined file is not required, and the combined file must contain both elements.
- The student can point at `title` and `h1` and say which one the test read.
- The scratch sentence is discussed and not submitted as a replacement for the lesson text.
