# 01 — An Unordered List

## 📚 Subject
A bulleted list of short items.

## 📖 Read About It
- MDN: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/ul
- W3Schools: https://www.w3schools.com/html/html_lists.asp

## 🎯 Task
Create a bulleted list of three things you have practiced:

1. Headings
2. Links
3. Images

Use `<ul>` and `<li>`. Keep that order.

## ✅ Requirements
- Use one `<ul>`.
- The three items must be exactly `Headings`, `Links`, and `Images`.
- Do not modify the test files.

## 🧪 Testing
From the repository root, run:

```bash
npm test -- 01-unordered-list
```

`npm test` checks every practice.

The concept notes are in [the study guide](../../../../curriculum/modules/html.profile/study-guide.md).

## 🔧 Debugging
- One `<ul>`. The items are exactly `Headings`, `Links`, and `Images`, in that order.
- Typed numbers inside the item text become part of the text.
- A later lesson uses different items. Do not paste this list there and expect a pass.

## ❓ Conceptual questions
1. Why is this a `<ul>` rather than three paragraphs?
2. What will the lesson 02 list add that this one does not?

## 🌱 Extension
Make a three-item list of your own topics in a scratch file. Keep these three words here. The extension is not graded.
