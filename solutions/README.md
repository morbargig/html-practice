# Reference solutions

Part of [HTML Practice](../README.md). These pages show one way to pass the tests. They exist so the test suite can be checked on its own. Each solution sits under `solutions/` at the same path as the practice it answers, for example `solutions/practices/lesson-01/01-text/01-hello-heading/`. The practice brief for that exercise is [practices/lesson-01/01-text/01-hello-heading/README.md](../practices/lesson-01/01-text/01-hello-heading/README.md).

Solve the practice first. Open a solution only after your own page is finished, or when you are fixing a test.
